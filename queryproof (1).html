How it works

  1. You type one question about an FDA drug recall.
  2. Queryproof writes a query for one index, drug_enforcement, and runs it on about 300 real FDA drug-enforcement records.
  3. It grades the query against a saved answer key. The grade checks facts, not JSON text: class, state, firm, start date, end date, and product words.
  4. You see the grade, then the recalls. The query itself is there if you want the evidence.

Grade the answer keys

Every question is graded on six facts. Each one is Pass or Miss. A fact you did not ask for is skipped. The score reads like “5 of 5”.

  • ClassPass
  • StatePass
  • FirmNot asked
  • Start dateMiss
  • End datePass
  • Product wordsPass

Layout key only. A Miss is a wrong fact. It is never the same as an empty result.
